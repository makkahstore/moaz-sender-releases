# مُرسِل الرسائل

نظام إدارة وجدولة حملات واتساب — برنامج مكتبي يشتغل على ويندوز.

## تحميل البرنامج

من صفحة [**الإصدارات (Releases)**](../../releases/latest) نزّل ملف `Moaz-Sender-Setup-x.x.x.exe` وشغّله.

لو ويندوز قال «تمت حماية جهازك»: دوس **مزيد من المعلومات** ثم **تشغيل على أي حال**. ده بيحصل مع أي برنامج جديد مش موثّق عند مايكروسوفت لسه.

## محتاج مفتاح تفعيل

البرنامج بيشتغل بمفتاح اشتراك. لو معندكش واحد، كلّمنا.
